# Go: учебные заметки и эксперименты

Небольшая коллекция программ, на которых вы можете разобраться с Go: от функций и указателей до горутин, каналов и синхронизации. Большинство примеров независимы друг от друга, а комментарии и вывод в консоль местами на русском.

## Что внутри

| Каталог                    | Темы                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------ |
| `func`                     | функции, параметры и возвращаемые значения                                           |
| `vetvlenia`                | ветвления и условия; продолжение — в `second part`                                   |
| `cycle`                    | циклы и небольшие эксперименты, включая `flappybird` и `for with rand`               |
| `defer`                    | отложенный вызов функций                                                             |
| `errors`                   | обработка ошибок, паника и `recover`                                                 |
| `greeting`                 | пример отдельного Go-пакета                                                          |
| `struct`                   | структуры, методы и простая валидация                                                |
| `interfac`                 | интерфейсы и методы                                                                  |
| `ukazateli`                | указатели и изменение значений через них                                             |
| `massive`                  | массивы и коллекции; примеры слайсов и map лежат во вложенных каталогах              |
| `goroutines`               | горутины, анонимные функции, `WaitGroup`, `select`, каналы, контексты и гонки данных |
| `http`                     | HTTP-серверы, обработчики запросов и работа с телом POST-запроса                     |
| `json`                     | кодирование платежей в JSON и HTTP-обработчик                                        |
| `SQLite`                   | создание SQLite-базы, добавление и обновление задач                                  |
| `concurrency(big example)` | параллельные пулы шахтёров и почтальонов, каналы, отмена контекста и синхронизация   |

## Запуск

Нужен установленный Go. В корне репозитория общего `go.mod` нет, поэтому простые примеры запускаются по файлу из своего каталога:

```powershell
Set-Location .\func
go run .\main.go
```

У нескольких каталогов есть собственный `go.mod`: `errors`, `massive`, `vetvlenia`, `SQLite` и `concurrency(big example)`. Для них запускайте программу из каталога модуля:

```powershell
Set-Location .\errors
go run .
```

В `errors` и `massive` указаны внешние зависимости, которые Go загрузит при первом запуске. Для другого примера замените путь на нужный файл или каталог, например `..\goroutines\waitgroup\main.go`.

## JSON и HTTP

В каталоге `json` находится HTTP-сервер, который принимает платежи в формате JSON,
проверяет данные, уменьшает баланс и возвращает текущий баланс вместе с историей платежей:

```powershell
Set-Location .\json
go run .\main.go
```

Сервер использует адрес `localhost:9091`. Отправьте POST-запрос на
`http://localhost:9091/pay` с заголовком `Content-Type: application/json` и телом:

```json
{
  "description": "Книга",
  "usd": 100,
  "FullName": "Иван Иванов",
  "address": "ivan@example.com"
}
```

## SQLite

Пример в каталоге `SQLite` создаёт локальную базу `tasks.db`, добавляет новую задачу,
просит ввести номер задачи для выполнения и затем выводит все задачи:

```powershell
Set-Location .\SQLite
go run .
```

Файл `tasks.db` создаётся в каталоге `SQLite` при первом запуске. Зависимость
`modernc.org/sqlite` позволяет запускать пример без CGO.

## HTTP и Postman

В каталоге `http` находятся примеры HTTP-серверов на Go. Для запуска основного сервера:

```powershell
Set-Location .\http
go run .\main.go
```

Сервер запускается на `localhost:9091`. Откройте Postman, создайте запросы и отправьте их на:

- `GET http://localhost:9091/` — сервер вернёт `Hello, world!`;
- `GET http://localhost:9091/sleep` — сервер вернёт ответ через 5 секунд.

В каталоге `http\body` есть пример обработки тела POST-запроса:

```powershell
Set-Location .\http\body
go run .\main.go
```

В Postman выберите метод `POST`, вкладку **Body** → **raw**, укажите тип **Text**
и передайте числовое значение:

- `POST http://localhost:9091/pay` — оплата указанной суммы;
- `POST http://localhost:9091/save` — перевод указанной суммы в копилку.

Результаты работы сервер выводит в консоль, в которой запущен `go run`.

## Примечание

Это учебные наброски, а не единое приложение или готовый набор тестов. Некоторые файлы могут быть незавершёнными; удобнее изучать и запускать их по одному.
