# Go: учебные заметки и эксперименты

Небольшая коллекция программ, на которых вы можете разобраться с Go: от функций и указателей до горутин, каналов и синхронизации. Большинство примеров независимы друг от друга, а комментарии и вывод в консоль местами на русском.

## Что внутри

| Каталог                    | Темы                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------ |
| `func`                     | функции, параметры и возвращаемые значения                                           |
| `vetvlenia`                | ветвления и условия; продолжение — в `second part`                                   |
| `cycle`                    | циклы и небольшие эксперименты, включая `flappybird` и `for with rand`               |
| `defer`                    | отложенный вызов функций                                                             |

| `struct`                   | структуры, методы и простая валидация                                                |
| `interfac`                 | интерфейсы и методы                                                                  |
| `ukazateli`                | указатели и изменение значений через них                                             |
| `massive`                  | массивы и коллекции; примеры слайсов и map лежат во вложенных каталогах              |

## Запуск

Нужен установленный Go. Для модулей учитывайте версию из их `go.mod`: в `SQLite`
указана Go 1.26.5, в остальных модулях — Go 1.27.1.

Все команды ниже выполняются из корня репозитория. Перед запуском следующего примера
вернитесь в корень или откройте новый терминал в нём.

В корне общего `go.mod` нет, поэтому простые примеры запускаются по файлу из своего каталога.
На macOS/Linux:

```sh
cd func
go run main.go
```

В PowerShell:

```powershell
Set-Location .\func
go run .\main.go
```

У нескольких каталогов есть собственный `go.mod`: `errors`, `massive`, `vetvlenia`, `SQLite` и `concurrency(big example)`. Для них запускайте программу из каталога модуля:

```powershell
Set-Location .\errors
go run .
```

На macOS/Linux используйте `cd errors` и `go run .`. Пути с пробелами или скобками
заключайте в кавычки, например `cd 'concurrency(big example)'`.

В `errors`, `massive` и `SQLite` указаны внешние зависимости, которые Go загрузит
при первом запуске. Вложенные примеры запускайте отдельно, например:

```sh
go run goroutines/waitgroup/main.go
```

## JSON и HTTP

В каталоге `json` находится HTTP-сервер, который принимает платежи в формате JSON,
проверяет данные, уменьшает баланс и возвращает текущий баланс вместе с историей платежей:

```powershell
Set-Location .\json
go run .\main.go
```

Сервер использует адрес `localhost:9091`. Отправьте POST-запрос на
`http://localhost:9091/pay` с заголовком `Content-Type: application/json` и телом:

```json
{
  "description": "Книга",
  "usd": 100,
  "FullName": "Иван Иванов",
  "address": "ivan@example.com"
}
```

## SQLite

Пример в каталоге `SQLite` демонстрирует работу с локальной базой задач через
`github.com/jmoiron/sqlx` и драйвер `modernc.org/sqlite`. Драйвер работает без CGO.

В примере используются:

- структура `Task` с полями `ID`, `Title`, `Done` и тегами `db`;
- `sqlx.Connect` для подключения к базе и `Exec` для создания таблицы, добавления и обновления задач;
- `Select` для чтения списка задач в `[]Task` и `Get` для чтения одной задачи;
- `sql.ErrNoRows` для обработки отсутствующей задачи и проверка статуса выполнения.

Запуск на macOS/Linux:

```sh
cd SQLite
go run .
```

В PowerShell:

```powershell
Set-Location .\SQLite
go run .
```

При запуске программа создаёт `tasks.db` и таблицу `tasks`, если их ещё нет.
Каждый запуск добавляет задачу «Разобраться с SQLite», выводит список задач
по возрастанию ID и запрашивает номер задачи для выполнения.
База сохраняется между запусками; её файл и служебные файлы SQLite исключены через
`SQLite/.gitignore`.

Введите ID из списка. Программа проверит выбранную задачу и отметит её выполненной.
Если задача уже выполнена или указанный ID отсутствует, появится соответствующее
сообщение. Обновлённый статус будет виден в списке при следующем запуске.

## HTTP и Postman

В каталоге `http` находятся примеры HTTP-серверов на Go. Для запуска основного сервера:

```powershell
Set-Location .\http
go run .\main.go
```

HTTP-примеры используют порт `9091`, поэтому запускайте по одному серверу за раз.
Остановить сервер можно сочетанием `Ctrl(cmd)+C`. Откройте Postman, создайте запросы
и отправьте их на `localhost:9091`:

- `GET http://localhost:9091/` — сервер вернёт `Hello, world!`;
- `GET http://localhost:9091/sleep` — сервер вернёт ответ через 5 секунд.

В каталоге `http\body` есть пример обработки тела POST-запроса:

```powershell
Set-Location .\http\body
go run .\main.go
```

В Postman выберите метод `POST`, вкладку **Body** → **raw**, укажите тип **Text**
и передайте числовое значение:

- `POST http://localhost:9091/pay` — оплата указанной суммы;
- `POST http://localhost:9091/save` — перевод указанной суммы в копилку.

Результаты работы сервер выводит в консоль, в которой запущен `go run`.

## Примечание

Это учебные наброски, а не единое приложение или готовый набор тестов. Некоторые файлы могут быть незавершёнными; удобнее изучать и запускать их по одному.
